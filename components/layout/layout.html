The Seed layout is a three-panel app shell built on CSS Grid. Each panel is a card. The left panel holds navigation, the center panel holds content, and the right panel holds context or details. Panels can be docked, hidden, or floated as overlays.

Left
Center
Right
Resize Drag the column handles to resize left and right panels. Width is stored as a CSS custom property.
Hide & float Each panel can be hidden or detached into a floating overlay card via the ··· context menu.
Responsive Right panel hides at ≤ 1024px. Left panel hides at ≤ 768px and becomes a slide-in overlay.
Dark mode Toggle via the theme switcher. All colors use Seed semantic tokens — zero hardcoded values.

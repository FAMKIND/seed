The Seed identity — minimal wordmark, sprout mark, and a warm neutral foundation. Built for open source, made to grow.

Font family: Montserrat Semibold for the wordmark. Icon: the 🌱 sprout emoji as placeholder — swap for a custom SVG mark later. Maintain clear space equal to the avatar height on all sides.

Semantic color tokens — theme-responsive. Every token is live: switch to dark mode and all swatches update automatically.
